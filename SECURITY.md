# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not
open a public issue or pull request containing API keys, tokens, passwords, or
other sensitive data.

If a credential is exposed, revoke or rotate it immediately, then include only
the affected file, commit, workflow run, or public URL in the private report.

## Public-data scope

This project intentionally analyzes public App Store and Google Play content.
Review text may be republished as research evidence; do not add private data,
credentials, or non-public datasets to the repository or Pages artifacts.
